# Student Portfolio Website

A beginner-friendly personal portfolio built with HTML, CSS, and JavaScript.

## Before publishing
1. Replace `Your Name` and `YourName` with your name.
2. Replace the sample email with your email.
3. Update the GitHub Profile link in `index.html`.
4. Edit the skills and project descriptions to match your real experience.
5. Add links to your project repositories when you have them.

## Run it on your computer
Open this folder in Visual Studio Code. Open `index.html` in a browser. You may install the Live Server extension in VS Code for a live preview.

## Publish with GitHub Pages
1. Create a GitHub repository named `yourusername.github.io`, replacing `yourusername` with your GitHub username.
2. Put `index.html`, `style.css`, and `script.js` in the repository's root folder.
3. Commit and push the files to GitHub.
4. In the repository, open **Settings → Pages**.
5. Under the build/deployment settings, select **Deploy from a branch**, choose `main` and `/(root)`, then save if the option appears.
6. Wait for GitHub Pages to publish. Your site address will be `https://yourusername.github.io/`.

## Daily Git workflow
After making a meaningful change, open a terminal in this folder and run:

```bash
git add .
git commit -m "Describe the change"
git push
```

For your first push, follow GitHub's repository setup instructions if you have not connected this local folder to the repository yet. Do not make empty commits just to increase the count. Make and record real progress.
